# Student card templates

Unmodified student card backgrounds extracted from VTC@HK Android 4.0.16,
`res/drawable/e_card_template_student_*`. Original PNG/WebP formats are retained.
These are blank templates; no student photos, credentials, or personal card data
are included. Artwork and branding belong to their respective VTC institutions.

`src/lib/student-card.ts` maps campus codes using the APK's ECardPagerAdapter.
YC and YCI are distinct templates. THEi uses a separate layout in the APK.
